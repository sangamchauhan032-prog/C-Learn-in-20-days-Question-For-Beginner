## How to Run the Programs

You need a C++ compiler such as GCC or MinGW.

1. Clone this repository:

```bash
git clone https://github.com/sangamchauhan032-prog/C-Learn-in-20-days-Question-For-Beginner.git
```

2. Open the project folder.

3. Compile any `.cpp` file:

```bash
g++ filename.cpp -o program
```

4. Run the program:

```bash
./program
```

On Windows PowerShell, use:

```powershell
.\program.exe
```
